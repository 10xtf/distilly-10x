# Roadmap do Distilly

*Última atualização: 2026-09-02*

O roadmap canônico está em [ROADMAP.md](../../ROADMAP.md). Esta página resume a Developer Preview da branch `codex/distilly-plugin`.

## Agora

O fluxo local TypeScript/SQLite do Codex foi verificado de ponta a ponta: materiais locais, versões, correções, revisão, cinco ferramentas MCP, instalação do Plugin e desinstalação segura.

## Prioridade da comunidade

Precisamos de ajuda para criar e validar bindings de Plugin para **Grok Bot, Claude Code, OpenCode, Pi agent e DeepSeek Harness (DSH)**. Cada integração deve ter launcher isolado, testes de setup/doctor/reinício/desinstalação e evidência exata de host e capacidade. Vou revisar essas contribuições ativamente.

## Depois

Marketplace do Panel, mais parsers locais e adapters autorizados, migração, backup/restore, diagnóstico profundo e outros hosts virão depois que a Preview estiver estável.
