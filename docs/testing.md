# Testing

Commands live in root [AGENTS.md](../AGENTS.md). This file is what a green run must mean.

## Tiers we have

- **Python unit** (`python3 -B scripts/run_tests.py`): stdlib unittest next to the behavior it pins. The runner fails when discovery finds zero tests. Prefer errors, skip paths, on-disk layout, and contract regressions.
- **Compile** (`python3 -m compileall -q tools scripts tests`): syntax only. CI also compiles `src/` when that directory exists.
- **Docs** (`python3 -B scripts/verify_docs.py`): portable local links, exact trailing newline, and canonical design projections. It does not prove prose is true.
- **Agent Notes** (`python3 -B scripts/verify_agent_notes.py`): lifecycle, path, date, status, required non-empty sections, and duplicate ownership. `--base <sha> --head <sha>` requires a newly added dedicated Note or that feature's lifecycle rename when governed paths change; modifying an existing or aggregate Note alone fails. `merge-base` owns feature/PR ranges and `direct` owns old-to-new push snapshots. The path gate does not prove that one Note hides multiple features or that its rationale is true; semantic review owns those checks.
- **Python lint** (`ruff check tools scripts tests`): blocking static errors. It is not a formatter or type checker.
- **TypeScript fast** (`pnpm run gates:fast`): Prettier check plus ESLint, including the type-aware Promise, discriminant, and public-contract rules configured for product sources. It does not typecheck package exports or run behavior.
- **TypeScript typecheck** (`pnpm run typecheck`): no-emit checks for every package and the repository tool configuration. A green result proves the current source graph typechecks, not that its built entry resolves.
- **TypeScript Protocol** (`pnpm run test` or a narrow Protocol Vitest file): Vitest covers all public id/time/facet grammars, strict wire and typed error envelopes, shared limits, host/private-capture values, method-correlated fact-record schema round-trips, every branch of the 35-method runtime schema registry, EngineEvent compatibility decoding, and all five MCP descriptor runtime/JSON-schema input and output contracts. Distilly extension keywords preserve byte and cross-field constraints that draft-2020-12 cannot express; the runtime schema remains the authoritative MCP boundary when a generic validator ignores those keywords. These tests prove serializable Protocol behavior, not persistence or Engine services.
- **Source-adapter contracts** (`pnpm exec vitest run packages/adapters/src`): offline fixtures cover both direct and delegated seams, strict adapter-owned resource parsing, malformed and duplicate registration, immutable content-free discovery, opaque secret references, exact four-method direct-user schemas, Protocol-owned nested values, closed action envelopes, finite byte-, fan-out-, cycle-, and depth-bounded extension resources, and UTF-8 input limits. They prove the provider-neutral contract and runtime boundary; they do not resolve a secret, contact a provider, parse exported files, dispatch collection, or add an EngineMethodMap/MCP method.
- **Engine SQLite create/ingest/brief/lease/commit/review/rollback** (`pnpm exec vitest run packages/engine/src`): real temporary SQLite/WAL roots cover the exact seventeen-table canonical private schema v1, pre-mutation rejection of malformed or future stores, foreign keys, current/suspended uniqueness, same-subject version lineage, private paths, typed storage failures, immutable SHA-256 blobs, standalone create, create-or-existing ingest, global RequestId replay/conflict, identity resolution, `auto-v1`, and transaction rollback. Pending/lease tests prove filter-before-limit ordering, exact expiry, complete and incremental briefing, capacity refusal, one concurrent lease owner, renew/release, generation changes, and exact canonical-template replay. Commit tests prove strict error precedence; 65,536-byte acceptance and 65,537-byte zero-write refusal; evidence/blob/lease/generation/pointer rechecks; deterministic current or suspended versions; sealed patch-digest authority; incremental baseline reuse; competing-writer serialization; stable replay; and atomic pending/lease cleanup. Review-query tests prove subject-filtered and paged active candidates, first-version diffs without an invented current baseline, direct status/pointer/version verification, and no dependency on unrelated pending rows. Promote/reject/rollback tests prove transaction-time active-candidate and historical-target checks, exact result replay and changed-input/actor/method conflict, direct-review reason and rollback-source events, immutable rollback descendants, single-winner decisions, reject's byte-identical pending preservation, and fresh unleased pending rebases for promote/rollback even when no old job exists. Real child-process tests kill brief, commit, promote, reject, and rollback immediately before and after COMMIT, then reopen SQLite to distinguish the previous world from the complete target and exact replay. A TypeScript-AST source-graph boundary keeps every still-unmigrated file authority, lock, recovery, queue, and projection outside the live SQLite composition. The Engine pack guard requires the production SQLite review/query composition and excludes retired mutation modules plus every `lib/testing` fixture. Package-internal verified reads and the Library projection remain packable but uncomposed until their owner migrations. This proves the current package-private slices, not defense against an attacker already controlling the same local filesystem account or a complete public Engine runtime.
- **Engine legacy verified reads and Library** (`pnpm exec vitest run packages/engine/src`): retained real fact-tree fixtures prove method/filter-bound cursors; current and historical profile, prompt, material, version, diff, lineage, and legacy active-review projections; first-version diff absence; and explicit raw-extract refusal. Read fixtures prove reconcile-before-snapshot locking, the post-subject-lock intent recheck/release/recovery order, and rejection of physical versions without exact creation events, dangling lineage references, contradictory decisions, or inconsistent rollback ancestry/copies. The copied file review query remains test-only coverage for those read snapshots; the former file review/rollback mutation service, journals, staging, recovery, and crash matrix are removed. JsonLibraryProjection fixtures cover canonical checksums and ordering, fact-derived privacy/quality/status/search terms, stable pages, incremental apply/remove, clean no-intent reads with zero transaction-history scan, exact dirty/intent-marker crash points, intent retention through retained journal terminalization, post-commit-before-dirty clean-stale prevention, rebuild ordering under contention, and corrupt/symlink fail-closed behavior.
- **Injected-client facade** (`pnpm exec vitest run packages/distilly/src`): mapping fixtures cover every `Distilly` and `Person` query and mutation, explicit and generated top-level RequestIds, subject binding, null-to-void projections, Web Crypto refusal, injected-client close delegation, and the exact browser-safe runtime export allowlist. These tests prove the facade over a complete injected `EngineClient`; they do not construct a local runtime or touch `DISTILLY_ROOT`.
- **MCP adapter and transport** (`pnpm exec vitest run packages/mcp/src`, then the package's built smoke through `pnpm run hygiene`): an official in-memory MCP client checks the exact five Protocol descriptors, every action-to-method projection, mutation context, successful empty branches, current versus suspended presentation, output parsing, redacted typed failures, admission draining, five-second close bound, and borrowed dependency ownership. The built smoke uses the official stdio client against a real child, initializes the server, lists the exact descriptors, calls all five tools plus an invalid input, compares structured content with its JSON text, and verifies bounded clean teardown with no stderr. Its child uses a full test-only EngineClient and presenter, so this is adapter and stdio conformance rather than a production backend, correction flow, or product e2e.
- **Host capability bindings** (`pnpm exec vitest run packages/bindings/src`): parameterized Codex and Claude Code fixtures validate the closed preflight union, direct-net handshake and exact versioned fixture evidence, host/environment/release/wire/skill matching, forced private-capture unavailability, provider failure normalization, and deterministic duplicate-safe registry ordering. They prove capability-only translation over an injected trusted provider; they do not probe a host executable, install a plugin, create an injector/form renderer, or construct a runtime.
- **Panel loopback HTTP** (`pnpm run test:panel-http`): real sockets prove the literal loopback origin, exact Bearer/Host/Origin boundary, fixed assets/CSP and person-free health response, complete method-correlated RPC parsing, domain failures inside HTTP 200, fixed transport status mapping, all-mutation one-use nonce binding and atomic consumption, exact expiry, 4 MiB request and 16 MiB response bounds, 16 KiB header/SSE bounds, subscribe-before-ready watch streaming, symlink refusal, occupied-port failure, launcher races, browser-fragment token removal, SSE byte decoding, unknown-event full reread, reconnect behavior, and borrowed-client ownership.
- **Panel Chromium** (`pnpm run test:panel-browser`): the built browser bundle runs in real Chromium against the real loopback server and a complete injected test EngineClient. The scenario verifies the exact review route; token removal and non-persistence; Library, Subject, Review, evidence/source, materials, versions, and Settings/Doctor rendering; user-confirmed rollback/promote/reject through real nonce and RPC requests; authenticated `POST /events`; unknown-event and reconnect full rereads; no remote asset requests; and zero browser errors. This is Panel server/web end-to-end evidence, not a production runtime or local fact-backend end-to-end.
- **Plugin release assembly** (`pnpm run test:plugins`, with `pnpm run check:plugins` in hygiene): real temporary trees cover recursive raw-byte file digests, UTF-8 POSIX path order, the domain-separated canonical tree digest, exact Codex/Claude mirrors, stale pruning, SemVer propagation, platform manifest digests, source-only MCP template shapes, and compact schema-versioned release-manifest bytes. Symlink, special-file, path escape, source/target drift, two-copy stale, forged digest, version, and template negatives fail closed. Check mode reassembles under a clean temporary root and compares generated bytes; it proves source release integrity, not setup or a launchable plugin.
- **Package boundaries** (`pnpm run test:boundaries`, also enforced by `pnpm run hygiene`): a fail-closed TypeScript-AST checker verifies the current internal allowlist `@distilly/adapters → @distilly/protocol`, `@distilly/engine → @distilly/protocol`, `distilly → @distilly/protocol`, `@distilly/mcp → @distilly/protocol`, `@distilly/bindings → @distilly/protocol`, and `@distilly/panel → @distilly/protocol + @distilly/mcp`, while Protocol has no internal dependency and packages have no upward or mutual edge. Seeded negative fixtures cover both directions around Adapters, Panel, bindings, Facade, and MCP plus manifest/source direction, cross-package relative-import refusal, static module specifiers, and cycle detection. The checker resolves `npm:` and `workspace:` aliases plus local `link:`, directory `file:`, and bare directory specs, including source imports through an alias subpath, back to the real internal package; renaming the dependency key cannot bypass the graph. Knip remains responsible for unused and undeclared dependency hygiene.
- **Coverage** (`pnpm run test:coverage`): reports V8 coverage for TypeScript product sources without a per-file percentage gate. It is evidence of exercised lines, not semantic completeness.
- **Snapshots** (`pnpm run snapshots`): pins the Protocol root's complete explicit type/runtime symbol allowlists, wire vocabulary, 35-method order, and every serializable field of the exact five MCP descriptors, including their draft-2020-12 input/output schemas, `x-distilly-*` constraints, and annotations. It also pins the Adapters, Facade, MCP, bindings, and Panel runtime/type export allowlists; the MCP root and stdio export split plus server identity source; the Panel browser-only dependency graph; and the packaged host-distill prompt, content-addressed prompt version, contract digest, source-grouping version, and evidence rules without a model key. The canonical plugin skill is protected by recursive byte digests and a reviewed source diff rather than a model execution snapshot; no production public client is constructible yet.
- **Build and package face** (`pnpm run build`, then `pnpm run hygiene`): the build validates the root's direct TypeScript references, removes only their real non-symlink `lib/` directories, and then emits all seven current packages, so deleted source cannot survive as stale package output. The boundary and plugin assembly checkers, Knip, built-entry import smokes, Engine dry-run pack allowlist, publint, and `attw --pack --profile esm-only` check dependency direction, generated release bytes, unused or undeclared dependencies, runtime importability, test/fixture exclusion, retired artifact removal, exports, and published type resolution. The Adapters smoke imports only its reviewed root and exercises built registration plus secret-ref validation; the private Engine root smoke pins that no incomplete runtime API leaks while exercising built SQLite ingest, brief, commit, active-review query, promote, immutable rollback, reopen/replay, exact version authority, cross-process create contention, and process-kill transaction boundaries; the Facade smoke rejects Node built-ins; the MCP smoke exercises stdio through a real child; the bindings smoke imports its built package name and validates both capability factories; and the Panel smoke imports only its two reviewed subpaths and verifies packaged local assets. Source tests alone do not establish these properties.
- **CI** on `dot-skill`, `distilly`, and `main` runs governance once, the TypeScript workspace, Protocol and source-adapter contracts, Engine slices, injected Facade/MCP tests, capability binding tests, Panel HTTP and real Chromium tests, plugin assembly, and built stdio conformance on Node 22.19 and 24 across Linux and macOS, plus the retained Python 3.9/3.11 and Ruff lanes. Locally run only what the diff can break.

We do not have, and do not pretend to have: a complete public Engine service; a full-method `DISTILLY_ROOT` backend; a concrete source adapter, any MaterialParser surface or implementation, or a user collection service; production MCP/CLI/setup/Panel composition; correction/evolution services; a full host binding or injector/form renderer; an installed/launchable plugin; a public host workflow or fresh-install test; per-file 100% coverage; a constructible public local client; or a real local-backend e2e.

The remaining TypeScript tiers — correction and the remaining public read/projection migration into SQLite/WAL, a complete public client, production runtime/MCP/CLI/Panel composition, host workflows, installation, and fresh-install acceptance — are specified in [design §27](design/v3/27-testing-and-governance.md). They are designed, not available, and cannot be cited as current evidence. Storage tests use real temporary SQLite/WAL and blob files, kill only at blob/transaction/projection/backup boundaries, and separate ordinary targeted-read checks from full doctor/restore audits; they do not preserve the old per-file crash matrix as a target.

## Rules

- Tests describe behavior, not correctness theater. Change obsolete behavior with its tests.
- Mock only the expensive or non-deterministic edge (network, clock, LLM). Keep the store, hasher, and renderer real.
- Assert the world: files under a temporary root, version pointers, claim lines, refusal errors. Do not trust an agent's own summary.
- Do not hit live APIs in CI.
- A test of an installer or CLI boots that entry, not an internal helper that skips argument parsing.
- Distill correctness: the same material-set hash skips automatically; accepted patches render byte-stably, while an explicitly requested external-model redistill may propose a different evidence-bounded patch and must be diffed/versioned rather than called deterministic.
- A test command that discovers zero tests is not evidence. Required test directories and entry points fail closed.
