# Testing

Commands live in root [AGENTS.md](../AGENTS.md). This file is what a green run must mean.

## Tiers we have

- **Python unit** (`python3 -B scripts/run_tests.py`): stdlib unittest next to the behavior it pins. The runner fails when discovery finds zero tests. Prefer errors, skip paths, on-disk layout, and contract regressions.
- **Compile** (`python3 -m compileall -q tools scripts tests`): syntax only. CI also compiles `src/` when that directory exists.
- **Docs** (`python3 -B scripts/verify_docs.py`): portable local links, exact trailing newline, and canonical design projections. It does not prove prose is true.
- **Agent Notes** (`python3 -B scripts/verify_agent_notes.py`): lifecycle, path, date, status, required non-empty sections, and duplicate ownership. `--base <sha> --head <sha>` requires a newly added dedicated Note or that feature's lifecycle rename when governed paths change; modifying an existing or aggregate Note alone fails. `merge-base` owns feature/PR ranges and `direct` owns old-to-new push snapshots. The path gate does not prove that one Note hides multiple features or that its rationale is true; semantic review owns those checks.
- **Python lint** (`ruff check tools scripts tests`): blocking static errors. It is not a formatter or type checker.
- **TypeScript fast** (`pnpm run gates:fast`): Prettier check plus ESLint, including the type-aware Promise, discriminant, and public-contract rules configured for product sources. It does not typecheck package exports or run behavior.
- **TypeScript typecheck** (`pnpm run typecheck`): no-emit checks for every package and the repository tool configuration. A green result proves the current source graph typechecks, not that its built entry resolves.
- **TypeScript Protocol** (`pnpm run test` or a narrow Protocol Vitest file): Vitest covers all public id/time/facet grammars, strict wire and typed error envelopes, shared limits, host/private-capture values, method-correlated fact-record schema round-trips, every branch of the 35-method runtime schema registry, EngineEvent compatibility decoding, and all five MCP descriptor runtime/JSON-schema input and output contracts. Distilly extension keywords preserve byte and cross-field constraints that draft-2020-12 cannot express; the runtime schema remains the authoritative MCP boundary when a generic validator ignores those keywords. These tests prove serializable Protocol behavior, not persistence or Engine services.
- **Source-adapter and local-parser boundary** (`pnpm exec vitest run packages/adapters/src`): offline fixtures cover both direct and delegated source seams, strict adapter-owned resource parsing, malformed and duplicate source registration, immutable content-free discovery, opaque secret references, exact four-method direct-user schemas, Protocol-owned nested values, closed action envelopes, finite byte-, fan-out-, cycle-, and depth-bounded extension resources, and UTF-8 input limits. Parser fixtures cover exact lowercase media-type registration, fatal UTF-8 validation, whitespace refusal, recursively stable JSON, SRT/VTT cleanup, deterministic output, and the exact/+1 byte limit without truncation. They prove the provider-neutral boundary and the five local parsers; they do not resolve a secret, contact a provider, dispatch collection, or add an EngineMethodMap/MCP method.
- **Engine SQLite create/ingest/brief/lease/commit/review/rollback/correction and Preview reads** (`pnpm exec vitest run packages/engine/src`): real temporary SQLite/WAL roots cover the exact nineteen-table canonical private schema v1, pre-mutation rejection of malformed or future stores, foreign keys, current/suspended uniqueness, same-subject version lineage, private paths, typed storage failures, immutable SHA-256 text/raw blobs, standalone create, create-or-existing text/file ingest, global RequestId replay/conflict, identity resolution, `auto-v1`, and transaction rollback. Pending/lease tests prove filter-before-limit ordering, exact expiry, complete and incremental briefing, capacity refusal, one concurrent lease owner, renew/release, generation changes, and exact canonical-template replay. Commit tests prove strict error precedence; 65,536-byte acceptance and 65,537-byte zero-write refusal; evidence/blob/lease/generation/pointer rechecks; deterministic current or suspended versions; sealed patch-digest authority; incremental baseline reuse; competing-writer serialization; stable replay; and atomic pending/lease cleanup. Review-query tests prove subject-filtered and paged active candidates, first-version diffs without an invented current baseline, direct status/pointer/version verification, and no dependency on unrelated pending rows. Promote/reject/rollback tests prove transaction-time active-candidate and historical-target checks, exact result replay and changed-input/actor/method conflict, direct-review reason and rollback-source events, immutable rollback descendants, single-winner decisions, reject's byte-identical pending preservation, and fresh unleased pending rebases for promote/rollback even when no old job exists. Correction tests prove normalized private evidence, trusted direct/relayed provenance, one full-body `user_asserted` replacement, current or suspended disposition, candidate replacement lineage, zero-delta pending/brief behavior, and exact replay/conflict. Preview-read tests execute create, ingest, commit, current and historical Profile/material/version reads, raw-extract verification, semantic diff, lineage, subject resolution, Library search/status/privacy, close/reopen, suspended review, reject, correction, rollback, and pending-only material-set corruption against the same SQLite authority. Real child-process tests kill brief, commit, promote, reject, rollback, and correction immediately before and after COMMIT, then reopen SQLite to distinguish the previous world from the complete target and exact replay. A TypeScript-AST source-graph boundary keeps every file authority, lock, recovery, queue, and projection outside the live SQLite composition. The Engine pack guard requires the production SQLite review/query/correction composition and excludes retired mutation modules plus every `lib/testing` fixture. This proves the current package-private slices, not defense against an attacker already controlling the same local filesystem account or a complete public Engine runtime.
- **Developer Preview runtime** (`pnpm exec vitest run packages/engine/src/preview.test.ts packages/runtime/src/preview.test.ts`): real temporary roots cover normalized in-process owner reservation, failed-open release, trusted actor/capacity parsing, engine-owned per-client lease isolation, exact params/context/result validation, explicit deferred-method failure, session watch/close isolation, runtime drain, create-through-prompt local flow, and close/reopen persistence. Local-file fixtures add parsed plus raw-only atomic ingest, RequestId replay before rereading deleted paths, cross-input/actor/method conflicts, zero-delta pending preservation, one canonical text tuple per raw, raw CAS verification after reopen, safe missing-file failure, and no persisted absolute path. Host-operation and CLI source fixtures additionally prove exact replay before projection, version agreement, fail-closed missing bindings, uninstall provenance, and stable install/export/uninstall completion through the Engine ledger. Built smokes pin both stable roots empty and exercise the opt-in Preview subpaths by package name. These unit and built-entry checks prove one real in-process local backend and its binding-backed Codex projection path; the separate packaged verifier proves self-contained installation. Neither proves daemon/RPC attach, concurrent host processes, crash takeover, maintenance, or source providers.
- **Engine legacy verified reads and Library** (`pnpm exec vitest run packages/engine/src`): retained real fact-tree fixtures prove method/filter-bound cursors; current and historical profile, prompt, material, version, diff, lineage, and legacy active-review projections; first-version diff absence; and explicit raw-extract refusal. Read fixtures prove reconcile-before-snapshot locking, the post-subject-lock intent recheck/release/recovery order, and rejection of physical versions without exact creation events, dangling lineage references, contradictory decisions, or inconsistent rollback ancestry/copies. The copied file review query remains test-only coverage for those read snapshots; the former file review/rollback mutation service, journals, staging, recovery, and crash matrix are removed. JsonLibraryProjection fixtures cover canonical checksums and ordering, fact-derived privacy/quality/status/search terms, stable pages, incremental apply/remove, clean no-intent reads with zero transaction-history scan, exact dirty/intent-marker crash points, intent retention through retained journal terminalization, post-commit-before-dirty clean-stale prevention, rebuild ordering under contention, and corrupt/symlink fail-closed behavior.
- **Injected-client facade** (`pnpm exec vitest run packages/distilly/src`): mapping fixtures cover every `Distilly` and `Person` query and mutation, explicit and generated top-level RequestIds, subject binding, null-to-void projections, Web Crypto refusal, injected-client close delegation, and the exact browser-safe runtime export allowlist. These tests prove the facade over a complete injected `EngineClient`; they do not construct a local runtime or touch `DISTILLY_ROOT`.
- **MCP adapter and transport** (`pnpm exec vitest run packages/mcp/src`, then the package's built smoke through `pnpm run hygiene`): an official in-memory MCP client checks the exact five Protocol descriptors, every action-to-method projection, mutation context, successful empty branches, current versus suspended presentation, output parsing, redacted typed failures, admission draining, five-second close bound, and borrowed dependency ownership. The built smoke uses the official stdio client against a real child, initializes the server, lists the exact descriptors, calls all five tools plus an invalid input, compares structured content with its JSON text, and verifies bounded clean teardown with no stderr. Its child uses a full test-only EngineClient and presenter, so this is adapter and stdio conformance rather than a production backend, correction flow, or product e2e.
- **Preview MCP application and CLI lifecycle** (`pnpm exec vitest run packages/cli/src`, then `pnpm --filter @distilly/cli run smoke:built` after build): a real temporary SQLite root drives `Distilly`/`Person`, create, ingest, brief, commit, get/prompt, direct correction, ordered close, and reopen. It then installs and exports a self-contained Codex person Skill, proves exact RequestId replay/conflict, reopens the Profile, and uninstalls only the owned projection. Lifecycle fixtures cover exact Codex version probing, unknown-version and unverified-Claude zero-write refusal, release-bound capacity selection, same-release setup replay, the fixed Codex host argument, narrow doctor, lifecycle-byte and parent-symlink refusal, failed-setup cleanup, bootstrap removal, packaged-runtime copy/ownership, tamper refusal, and preservation of both person data and a separately installed person Skill. Built children use compiled package bytes: one starts the private stdio Preview composition, opens the built Panel in Chromium from real correction ReviewLaunch URLs, reads Library/Subject/Review state from that same SQLite root, promotes and rejects candidates, rolls back to the initial historical version, verifies each result through MCP, and verifies the reopened Profile; the other uses the real binary for Codex setup and doctor, rejects deferred Claude setup, starts the installed absolute launcher with the official MCP client, lists exactly five tools, and uninstalls while retaining SQLite and person data. `pnpm run package:preview:codex` creates the actual digest-owned `0.1.0-preview.1` Codex artifact. The opt-in real-host package verifier installs it from a path with spaces and non-ASCII characters, removes the extraction, validates official plugin/MCP discovery and the exact five descriptors, repeats initialization without `CODEX_HOME` to match a Codex-spawned MCP child, runs create/ingest/brief/commit/get/prompt/correction plus real Panel promotion, invokes the explicit human person-install command, verifies Plugin and person-Skill discovery in fresh Codex processes without model calls, then proves uninstall preserves SQLite and the person Skill byte-for-byte. The immutable Codex evidence record was regenerated for this release through real `codex exec` observations at exact 65,536-byte tool-result and complete-briefing budgets. This proves the self-contained Codex Preview lifecycle; it does not prove cross-process sharing, crash takeover, upgrade, deep Doctor, or Claude activation.
- **Host bindings** (`pnpm exec vitest run packages/bindings/src`): parameterized Codex and Claude Code fixtures validate the closed preflight union, exact evidence tuple, forced private-capture unavailability, and duplicate-safe registry. Real temporary homes additionally cover absolute-launcher MCP rendering with an exact host argument, canonical skill bytes, sentinel/template exclusion, the validated Codex companion `mcpServers` shape, Claude Code skills-directory layout, Codex personal-marketplace neighbor preservation and exact add/remove selectors, explicit `CODEX_HOME` isolation, replacement rollback, fail-closed unowned/symlink/tampered projections, doctor/uninstall agreement on the exact owned file set, stable person-install replay, missing-launcher/version doctor results, prompt-only subrun injection, and Plugin uninstall retaining unrelated `~/.distilly/` data. - **Plugin and Codex package assembly** (`pnpm run test:plugins`, `pnpm run check:plugins`, and `pnpm run package:preview:codex`): real temporary source trees cover recursive raw-byte file digests, UTF-8 POSIX path order, the domain-separated canonical tree digest, exact Codex/Claude mirrors, stale pruning, SemVer propagation, platform manifest digests, source-only MCP template shapes, and compact schema-versioned release-manifest bytes. Symlink, special-file, path escape, source/target drift, two-copy stale, forged digest, version, and template negatives fail closed. Check mode reassembles source outputs under a clean temporary root and compares generated bytes. The Codex package assembler starts only from compiled production output and rejects source inputs, symlinks, workspace dependencies, tests/fakes, sentinel bytes, and checkout paths before writing its own exact file-digest manifest. Its built safety smoke proves `--force` refuses a populated unowned directory without changing its marker; replacement removes only a prior artifact that still passes full manifest/digest verification, and only after the new staging package is complete. Installed plugin bytes additionally pass the Codex plugin validator. The source release gate alone is not setup evidence; the packaged verifier supplies that evidence.
- **Package boundaries** (`pnpm run test:boundaries`, also enforced by `pnpm run hygiene`): a fail-closed TypeScript-AST checker verifies the leaf edges—including `@distilly/runtime → Protocol + Adapters + Bindings + Engine`—plus outer `@distilly/cli → Protocol + Bindings + Runtime + Facade + MCP + Panel`, while Protocol has no internal dependency and lower packages cannot reach upward into composition. Seeded fixtures cover both accepted edges, both directions around Adapters, Panel, bindings, Facade, and MCP, manifest/source direction, cross-package relative-import refusal, static module specifiers, aliases, and cycle detection. Knip remains responsible for unused and undeclared dependency hygiene.
- **Coverage** (`pnpm run test:coverage`): reports V8 coverage for TypeScript product sources without a per-file percentage gate. It is evidence of exercised lines, not semantic completeness.
- **Snapshots** (`pnpm run snapshots`): pins the Protocol root's complete explicit type/runtime symbol allowlists, wire vocabulary, 35-method order, and every serializable field of the exact five MCP descriptors, including their draft-2020-12 input/output schemas, `x-distilly-*` constraints, and annotations. It also pins the Adapters, Facade, MCP, bindings, and Panel runtime/type export allowlists; the MCP root and stdio export split plus server identity source; the Panel browser-only dependency graph; and the packaged host-distill prompt, content-addressed prompt version, contract digest, source-grouping version, and evidence rules without a model key. The canonical plugin skill is protected by recursive byte digests and a reviewed source diff rather than a model execution snapshot; no production public client is constructible yet.
- **Build and package face** (`pnpm run build`, `pnpm run hygiene`, then `pnpm run package:preview:codex` for the local artifact): the build validates the root's direct TypeScript references, removes only their real non-symlink `lib/` directories, and emits all current packages so deleted source cannot survive as stale package output. Package hygiene checks dependency direction, release bytes, unused or undeclared dependencies, runtime imports, test exclusion, retired artifacts, exports, bin resolution, and type resolution. In addition to the leaf-package smokes, the private CLI library root stays empty while its built binary exercises local stdio/Panel/reopen plus Codex setup/doctor/launcher/uninstall and fail-closed Claude refusal. The package assembler uses code splitting with repository TypeScript path aliases disabled, rejects any workspace source input, and emits the versioned self-contained Codex directory. Source tests alone do not establish installability; the real-host verifier does.
- **CI** on `dot-skill`, `distilly`, and `main` runs governance once, the TypeScript workspace, Protocol and source-adapter contracts, Engine slices, injected Facade/MCP tests, capability binding tests, Panel HTTP and real Chromium tests, plugin assembly, and built stdio conformance on Node 22.19 and 24 across Linux and macOS, plus the retained Python 3.9/3.11 and Ruff lanes. Locally run only what the diff can break.

We do not have, and do not pretend to have: a complete production Engine service; a full-method or cross-process `DISTILLY_ROOT` backend; a concrete source provider or user collection service; remaining evolution services; upgrade/deep-doctor lifecycle; Claude packaged activation; per-file 100% coverage; a constructible stable public local client; or a published installed-product release. The first Preview parser set is deliberately limited to TXT, Markdown, JSON, SRT, and VTT. The self-contained package and fresh-install acceptance apply only to the local Codex `0.1.0-preview.1` artifact.

The remaining TypeScript tiers — a complete production runtime, cross-process host workflows, upgrade/deep Doctor, and the Claude half of packaged fresh-install acceptance — are specified in [design §27](design/v3/27-testing-and-governance.md). They are designed, not available, and cannot be cited as current evidence. Storage tests use real temporary SQLite/WAL and blob files, kill only at blob/transaction/projection/backup boundaries, and separate ordinary targeted-read checks from full doctor/restore audits; they do not preserve the old per-file crash matrix as a target.

## Rules

- Tests describe behavior, not correctness theater. Change obsolete behavior with its tests.
- Mock only the expensive or non-deterministic edge (network, clock, LLM). Keep the store, hasher, and renderer real.
- Assert the world: files under a temporary root, version pointers, claim lines, refusal errors. Do not trust an agent's own summary.
- Do not hit live APIs in CI.
- A test of an installer or CLI boots that entry, not an internal helper that skips argument parsing.
- Distill correctness: the same material-set hash skips automatically; accepted patches render byte-stably, while an explicitly requested external-model redistill may propose a different evidence-bounded patch and must be diffed/versioned rather than called deterministic.
- A test command that discovers zero tests is not evidence. Required test directories and entry points fail closed.
