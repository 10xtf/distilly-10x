# Testing

Commands live in root [AGENTS.md](../AGENTS.md). This file is what a green run must mean.

## Tiers we have

- **Python unit** (`python3 -B scripts/run_tests.py`): stdlib unittest next to the behavior it pins. The runner fails when discovery finds zero tests. Prefer errors, skip paths, on-disk layout, and contract regressions.
- **Compile** (`python3 -m compileall -q tools scripts tests`): syntax only. CI also compiles `src/` when that directory exists.
- **Docs** (`python3 -B scripts/verify_docs.py`): portable local links, exact trailing newline, and canonical design projections. It does not prove prose is true.
- **Agent Notes** (`python3 -B scripts/verify_agent_notes.py`): lifecycle, path, date, status, required non-empty sections, and duplicate ownership. `--base <sha> --head <sha>` also requires a changed Note for governed paths; `merge-base` owns feature/PR ranges and `direct` owns old-to-new push snapshots. It is not a design review.
- **Python lint** (`ruff check tools scripts tests`): blocking static errors. It is not a formatter or type checker.
- **TypeScript fast** (`pnpm run gates:fast`): Prettier check plus ESLint, including the type-aware Promise, discriminant, and public-contract rules configured for product sources. It does not typecheck package exports or run behavior.
- **TypeScript typecheck** (`pnpm run typecheck`): no-emit checks for every package and the repository tool configuration. A green result proves the current source graph typechecks, not that its built entry resolves.
- **TypeScript Protocol** (`pnpm run test` or a narrow Protocol Vitest file): Vitest covers all public id/time/facet grammars, strict wire and typed error envelopes, shared limits, host/private-capture values, method-correlated fact-record schema round-trips, every branch of the 35-method runtime schema registry, EngineEvent compatibility decoding, and all five MCP descriptor runtime/JSON-schema input and output contracts. Distilly extension keywords preserve byte and cross-field constraints that draft-2020-12 cannot express; the runtime schema remains the authoritative MCP boundary when a generic validator ignores those keywords. These tests prove serializable Protocol behavior, not persistence or Engine services.
- **Engine facts through claim commit** (`pnpm exec vitest run packages/engine/src`): real temporary roots cover canonical checksums and material hashes, atomic previous-or-target publication under injected failures, strict UTF-8 and stable-symlink refusal, verified fact stores and cross-record invariants, owner-bound locks, dead-owner stale-heartbeat recovery, and candidate-safe paths. Step 5 fixtures execute clean-root and existing-subject text ingest, globally idempotent RequestId replay/conflict, concurrent duplicate creation, exact `auto-v1` boundaries, and prepared-journal recovery. Step 6 fixtures prove deterministic `source-groups-v1`, complete version/claims baseline verification including evidence locators, incremental briefing construction, fail-closed host capacity limits, exact briefing replay, lease ownership/expiry/renew/release behavior, target-first lease recovery without briefing regeneration, third-state refusal, and queue v2 rebuild and ordering from authoritative state. Step 7 fixtures add ClaimId and VersionId goldens, evidence resolution and patch algebra, strength/quality/review ordering, injection-safe byte-stable rendering, current-versus-suspended commits, exact idempotent replay, hard-reject zero-write precedence, fully verified version/current projections, and target/previous/third-state recovery across every post-commit materialization. The built Engine smoke adds packaged-prompt loading, real-process subject-lock contention, two-process same-identity creation, and two-process same-lease commit contention. This proves the package-internal vertical slices, not defense against an attacker already controlling the same local filesystem account or a complete public Engine runtime.
- **Engine verified reads, review, rollback, and Library** (`pnpm exec vitest run packages/engine/src`): real fact trees prove method/filter-bound cursors; current and historical profile, prompt, material, version, diff, lineage, and active-review projections; first-version diff absence; and explicit raw-extract refusal. Read fixtures prove reconcile-before-snapshot locking, the post-subject-lock intent recheck/release/recovery order, and rejection of physical versions without exact creation events, dangling lineage references, contradictory decisions, or inconsistent rollback ancestry/copies. Review fixtures cover promote/reject single-winner CAS, immutable rollback copies, global RequestId replay/conflict, stale and foreign targets, pending-job preserve/rebase/clear rules, exact operation/event projections, prepared/committed/aborted journal validation, target/previous/third-state recovery, and safe cleanup. JsonLibraryProjection fixtures cover canonical checksums and ordering, fact-derived privacy/quality/status/search terms, stable pages, incremental apply/remove, clean no-intent reads with zero transaction-history scan, exact dirty/intent-marker crash points, intent retention through journal terminalization, post-commit-before-dirty clean-stale prevention, rebuild ordering under contention, and corrupt/symlink fail-closed behavior.
- **Injected-client facade** (`pnpm exec vitest run packages/distilly/src`): mapping fixtures cover every `Distilly` and `Person` query and mutation, explicit and generated top-level RequestIds, subject binding, null-to-void projections, Web Crypto refusal, injected-client close delegation, and the exact browser-safe runtime export allowlist. These tests prove the facade over a complete injected `EngineClient`; they do not construct a local runtime or touch `DISTILLY_ROOT`.
- **MCP adapter and transport** (`pnpm exec vitest run packages/mcp/src`, then the package's built smoke through `pnpm run hygiene`): an official in-memory MCP client checks the exact five Protocol descriptors, every action-to-method projection, mutation context, successful empty branches, current versus suspended presentation, output parsing, redacted typed failures, admission draining, five-second close bound, and borrowed dependency ownership. The built smoke uses the official stdio client against a real child, initializes the server, lists the exact descriptors, calls all five tools plus an invalid input, compares structured content with its JSON text, and verifies bounded clean teardown with no stderr. Its child uses a full test-only EngineClient and presenter, so this is adapter and stdio conformance rather than a production backend, correction flow, or product e2e.
- **Host capability bindings** (`pnpm exec vitest run packages/bindings/src`): parameterized Codex and Claude Code fixtures validate the closed preflight union, direct-net handshake and exact versioned fixture evidence, host/environment/release/wire/skill matching, forced private-capture unavailability, provider failure normalization, and deterministic duplicate-safe registry ordering. They prove capability-only translation over an injected trusted provider; they do not probe a host executable, install a plugin, create an injector/form renderer, or construct a runtime.
- **Panel loopback HTTP** (`pnpm run test:panel-http`): real sockets prove the literal loopback origin, exact Bearer/Host/Origin boundary, fixed assets/CSP and person-free health response, complete method-correlated RPC parsing, domain failures inside HTTP 200, fixed transport status mapping, all-mutation one-use nonce binding and atomic consumption, exact expiry, 4 MiB request and 16 MiB response bounds, 16 KiB header/SSE bounds, subscribe-before-ready watch streaming, symlink refusal, occupied-port failure, launcher races, browser-fragment token removal, SSE byte decoding, unknown-event full reread, reconnect behavior, and borrowed-client ownership.
- **Panel Chromium** (`pnpm run test:panel-browser`): the built browser bundle runs in real Chromium against the real loopback server and a complete injected test EngineClient. The scenario verifies the exact review route; token removal and non-persistence; Library, Subject, Review, evidence/source, materials, versions, and Settings/Doctor rendering; user-confirmed rollback/promote/reject through real nonce and RPC requests; authenticated `POST /events`; unknown-event and reconnect full rereads; no remote asset requests; and zero browser errors. This is Panel server/web end-to-end evidence, not a production runtime or local fact-backend end-to-end.
- **Plugin release assembly** (`pnpm run test:plugins`, with `pnpm run check:plugins` in hygiene): real temporary trees cover recursive raw-byte file digests, UTF-8 POSIX path order, the domain-separated canonical tree digest, exact Codex/Claude mirrors, stale pruning, SemVer propagation, platform manifest digests, source-only MCP template shapes, and compact schema-versioned release-manifest bytes. Symlink, special-file, path escape, source/target drift, two-copy stale, forged digest, version, and template negatives fail closed. Check mode reassembles under a clean temporary root and compares generated bytes; it proves source release integrity, not setup or a launchable plugin.
- **Package boundaries** (`pnpm run test:boundaries`, also enforced by `pnpm run hygiene`): a fail-closed TypeScript-AST checker verifies the current internal allowlist `@distilly/engine → @distilly/protocol`, `distilly → @distilly/protocol`, `@distilly/mcp → @distilly/protocol`, `@distilly/bindings → @distilly/protocol`, and `@distilly/panel → @distilly/protocol + @distilly/mcp`, while Protocol has no internal dependency and packages have no upward or mutual edge. Seeded negative fixtures cover Panel as well as bindings/Facade/MCP directions, manifest/source direction, cross-package relative-import refusal, static module specifiers, and cycle detection. The checker resolves `npm:` and `workspace:` aliases plus local `link:`, directory `file:`, and bare directory specs, including source imports through an alias subpath, back to the real internal package; renaming the dependency key cannot bypass the graph. Knip remains responsible for unused and undeclared dependency hygiene.
- **Coverage** (`pnpm run test:coverage`): reports V8 coverage for TypeScript product sources without a per-file percentage gate. It is evidence of exercised lines, not semantic completeness.
- **Snapshots** (`pnpm run snapshots`): pins the Protocol root's complete explicit type/runtime symbol allowlists, wire vocabulary, 35-method order, and every serializable field of the exact five MCP descriptors, including their draft-2020-12 input/output schemas, `x-distilly-*` constraints, and annotations. It also pins the Facade runtime/type export allowlists, the MCP root and stdio export split plus server identity source, the bindings runtime/type allowlists, the Panel server/web subpath allowlists and browser-only dependency graph, and the packaged host-distill prompt, content-addressed prompt version, contract digest, source-grouping version, and evidence rules without a model key. The canonical plugin skill is protected by recursive byte digests and a reviewed source diff rather than a model execution snapshot; no production public client is constructible yet.
- **Build and package face** (`pnpm run build`, then `pnpm run hygiene`): TypeScript project references emit all six current packages; the boundary and plugin assembly checkers, Knip, built-entry import smokes, publint, and `attw --pack --profile esm-only` check dependency direction, generated release bytes, unused or undeclared dependencies, runtime importability, exports, and published type resolution. The private Engine root smoke pins that no incomplete runtime API leaks while exercising built cross-process locking; the Facade smoke rejects Node built-ins; the MCP smoke exercises stdio through a real child; the bindings smoke imports its built package name and validates both capability factories; and the Panel smoke imports only its two reviewed subpaths and verifies packaged local assets. Source tests alone do not establish these properties.
- **CI** on `dot-skill`, `distilly`, and `main` runs governance once, the TypeScript workspace, Protocol contract, Engine slices, injected Facade/MCP tests, capability binding tests, Panel HTTP and real Chromium tests, plugin assembly, and built stdio conformance on Node 22.19 and 24 across Linux and macOS, plus the retained Python 3.9/3.11 and Ruff lanes. Locally run only what the diff can break.

We do not have, and do not pretend to have: a complete public Engine service, production MCP/CLI/setup/Panel composition, a `DISTILLY_ROOT` backend, correction/evolution services, a full host binding or injector/form renderer, an installed/launchable plugin, a public host workflow or fresh-install test, per-file 100% coverage, a constructible public local client, or a real local-backend e2e.

The remaining TypeScript tiers — a complete public client over the package-internal profile/review handlers, correction and evolution, production runtime/MCP/CLI/Panel composition, host workflows, installation, and fresh-install acceptance — are specified in [design §27](design/v3/27-testing-and-governance.md). They are designed, not available, and cannot be cited as current evidence.

## Rules

- Tests describe behavior, not correctness theater. Change obsolete behavior with its tests.
- Mock only the expensive or non-deterministic edge (network, clock, LLM). Keep the store, hasher, and renderer real.
- Assert the world: files under a temporary root, version pointers, claim lines, refusal errors. Do not trust an agent's own summary.
- Do not hit live APIs in CI.
- A test of an installer or CLI boots that entry, not an internal helper that skips argument parsing.
- Distill correctness: the same material-set hash skips automatically; accepted patches render byte-stably, while an explicitly requested external-model redistill may propose a different evidence-bounded patch and must be diffed/versioned rather than called deterministic.
- A test command that discovers zero tests is not evidence. Required test directories and entry points fail closed.
