# Celebrity Budget-Unfriendly Research Audit Prompt

## 과제

synthesis 이전에 6트랙 공개 인물 조사 결과를 감사한다.

다음을 읽는다:

- `knowledge/research/raw/` 아래의 모든 파일
- `knowledge/research/merged/summary.md`
- `references/celebrity_budget_unfriendly_framework.md`

감사 결과는 `knowledge/research/reviews/research_audit.md` 에 쓴다.

## 감사의 책임

이 감사는 통과 여부를 가르는 게이트다. 장식용 요약으로 취급하지 않는다.
조사 결과가 synthesis로 넘어갈 준비가 되었는지 판정해야 한다.

FAIL은 조사에 보완이 더 필요하다는 뜻이다. PASS는 synthesis를 진행해도 된다는 뜻이다.

## 필수 섹션

다음 구조를 사용한다:


## 감사 규칙 — FAIL 조건

다음 중 하나라도 해당하면 감사를 불합격 처리한다:

- 6트랙 세트가 불완전하다 (어느 항목이든 누락)
- 트랙들이 의미 있게 구분되지 않는다 (파일 간에 관찰이 복제됨)
- 근거 URL이 얇거나 품질이 낮다 (실제로 열어 본 페이지 8건 미만)
- 논평 대비 1차 자료가 너무 약하다 (1차 50% 미만)
- 블랙리스트 출처가 근거로 사용되었다
- 모순이 없거나 뭉개져 있다 (실질적 긴장 3건 미만)
- 멘탈 모델 3개를 뒷받침할 근거가 부족하다
- known-answer bank가 이후 validation을 지탱하기에 너무 약하다 (질문 2개 미만)
- 단편 대비 장문 출처의 비중이 낮다
- 출처 위계가 하위에 몰려 있다 (대부분 가중치 5-7 출처)

## 감사 규칙 — PASS 조건

다음을 모두 충족하면 감사를 통과 처리한다:

- 6개 항목이 모두 의미 있게 구분되는 내용으로 채워져 있다
- 실제로 열어 본 페이지에서 나온 근거 URL 8건 이상
- 1차 출처 비율 50% 초과
- 블랙리스트 출처 없음
- 실질적 모순 3건 이상 기록
- 항목을 교차하는 근거를 가진 멘탈 모델 후보 3개 이상
- 근거 기준점이 있는 known-answer 질문 2개 이상
- 경계 사례 질문 1개 이상
- 선별 원칙이 합리적으로 지켜졌다 (장문 자료 존재, 1차 자료 우선)

## 저작권 안전

- 감사 결과에 긴 원문 구절을 붙여 넣지 않는다
- 모든 노트는 의역하고 출처를 밝힌 상태로 유지한다
