# Celebrity Budget-Unfriendly Persona Builder

## 과제

전체 조사 파이프라인을 사용해 공개 인물의 더 깊은 `persona.md` 를 생성한다:

- 6트랙 조사 노트
- research audit
- synthesis 리뷰
- validation 리뷰
- `references/celebrity_budget_unfriendly_template.md`

이 모드는 표준 builder보다 풍부하고 근거가 더 잘 뒷받침된 페르소나를 산출한다.

---

## 요구사항

- 모든 멘탈 모델은 맥락이 다른 기준점 최소 2건으로 근거가 뒷받침되어야 한다
- 표현 DNA는 100단어 블라인드 식별 테스트를 통과할 만큼 구체적이어야 한다
- 각 모델마다 정직한 한계와 실패 양상을 포함한다
- 실질적인 긴장(모순)을 최소 2건 포함한다
- 실제로 확인한 출처만 담은, 간결한 출처 근거 섹션을 포함한다
- 이 사람의 구체적 멘탈 모델에서 도출한 Agentic Protocol을 포함한다
- 구체적으로 빌려온 개념과 결별 지점이 담긴 지적 계보를 포함한다
- 전기적 사건이 아니라 사고의 변화를 보여 주는 인지 타임라인을 포함한다
- 아주 짧은 구절을 제외하고 모든 출처는 의역해서 쓴다
- validation 리뷰가 `FAIL` 이면 다듬어진 초안을 내보내지 않는다. 문제부터 고친다

---

## 구조

표준 celebrity persona builder와 같은 구조를 따르되, 다음 심화 요구사항을 추가한다:

### Layer 3 (멘탈 모델) — 강화

각 모델(총 3-7개)은 다음을 포함해야 한다:

- 이름과 한 줄 정의
- 먼저 보는 것 / 걸러내는 것
- 문제를 재구성하는 방식
- **근거 기준점**: 서로 다른 맥락에서 나온 사례 최소 2건 (의역, 출처 표시 포함)
- **실패 양상**: 이 모델이 그를 잘못된 길로 이끄는 경우는 언제인가? (근거가 있으면 함께)
- **적용 경계**: 이 모델을 적용해서는 **안 되는** 경우는 언제인가?
- **3중 게이트 결과**: 어떤 게이트를 통과했는지 (맥락 교차, 생성력, 배타성)

### Layer 4 (의사결정 휴리스틱) — 강화

각 휴리스틱(총 5-10개)은 다음을 포함해야 한다:

- 규칙 자체 ("X이면 Y")
- **뒷받침 사례**: 기록된 사례 최소 1건
- **맥락 경계**: 이 휴리스틱은 언제 적용되고 언제 적용되지 않는가?
- **표명 vs 드러남**: 그가 말하는 것과 일치하는가, 아니면 실제 행동에서만 나타나는가?

### Layer 5 (안티패턴과 한계) — 강화

- 구체적 근거가 있는 알려진 맹점 (일반론적인 "누구나 맹점이 있다"가 아니라)
- 각 정직한 한계마다, 어떤 자료를 추가하면 그 한계가 줄어드는지 명시한다
- 분류(시간적/맥락적/내재적)와 근거가 붙은 모순

### Layer 7 (Agentic Protocol) — 강화

Step 2의 조사 항목은 다음을 만족해야 한다:
- 이 사람의 검증된 멘탈 모델에서 직접 도출될 것
- 그의 분석 방식에 고유할 것 (일반적인 "데이터를 모으고, 분석하고, 결론짓는다"가 아니라)
- 신뢰할 출처와 불신할 출처를 포함할 것
- 무엇을 **가장 먼저** 알고 싶어 하는지 포함할 것 (그의 우선순위)

### 검증 기준점 (신규 섹션)

마지막에 다음을 포함한다:

```markdown
## Validation Anchors

### Known-Answer Tests
- Q: {이 사람이 공개적으로 답한 적 있는 질문}
  예상 방향: {근거에 기반해 그가 말할 내용}
  확신도: {높음/중간}

- Q: {두 번째 질문}
  예상 방향: ...

### Edge-Case Test
- Q: {직접적인 답이 알려지지 않은 인접 질문}
  예상 접근: {멘탈 모델에 기반해 그가 어떻게 추론할지}
  확신도: 낮음 — 외삽이다
```
