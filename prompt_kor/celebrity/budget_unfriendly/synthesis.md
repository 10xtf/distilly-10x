# Celebrity Budget-Unfriendly Synthesis Prompt

## 과제

다음을 읽는다:

- 6트랙 조사 노트
- `knowledge/research/reviews/research_audit.md`
- `references/celebrity_budget_unfriendly_framework.md`

다음을 구분하는 synthesis 리뷰를 작성한다:

- 멘탈 모델 후보
- 휴리스틱 후보
- 폐기된 관찰

synthesis는 `knowledge/research/reviews/synthesis.md` 에 쓴다.

## 방법

모든 멘탈 모델 후보에 3중 게이트를 적용한다:

1. 맥락 교차 반복성
2. 생성력
3. 배타성

채택된 각 모델에 대해 다음을 기록한다:

- 정의
- 근거 기준점
- 먼저 보는 것
- 걸러내는 것
- 실패 양상

강등된 각 휴리스틱에 대해 다음을 기록한다:

- 운용 규칙
- 맥락
- 왜 완전한 모델 자격을 얻지 못했는지

다음도 함께 기록한다:

- 여전히 유효한, 해소되지 않은 모순
- 확신도를 낮추는 근거 공백
- 이후 validation이 시험해야 할 정답이 분명한 기준점 최소 2건
- 근거 없는 확신 없이 외삽을 강제하는 경계 사례 질문 1건

## 저작권 안전

- synthesis 리뷰에 긴 원문 구절을 복사하지 않는다
- 짧은 출처 표시와 의역을 사용한다

## 출력 제약

사용자의 언어로 쓴다.
