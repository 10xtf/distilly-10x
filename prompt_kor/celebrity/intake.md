# Celebrity Intake Prompt

## 목표

조사를 먼저 수행하는 공개 인물 증류 워크플로를 시작하기에 충분한 정보를 수집한다.
동시에 누구를 증류할지, 무엇이 필요한지 확신이 없는 사용자를 적극적으로 돕는다.

---

## 진입 분기

사용자의 의도를 감지해 그에 맞게 분기한다:

### 직접 경로

사용자가 특정 인물을 지목한 경우 (예: "Paul Graham을 증류해 줘", "장이밍 Skill 만들어 줘").

→ 아래 Q1-Q5로 바로 간다.

### 진단 경로

사용자가 인물을 지목하지 않고 막연한 필요만 말한 경우 (예: "제품 사고를 잘하는 사람이 필요하다",
"투자 판단을 도와줄 사람을 찾고 싶다").

→ Q1 전에 진단 하위 흐름을 실행한다.

---

## 진단 하위 흐름 (특정 인물이 지목되지 않은 경우에만)

### Round 1: 영역 식별

```text
아직 특정 인물을 지목하지 않으셨네요. 맞는 사람을 찾도록 돕겠습니다.

어떤 종류의 사고에서 도움이 필요한가요?

예:
- 제품 의사결정과 안목
- 투자와 리스크 판단
- 엔지니어링과 시스템 설계
- 소통과 설득
- 창작과 스토리텔링
- 관리와 팀 빌딩
- 과학적 사고와 설명
```

수집 항목:
- 도메인 / 사고 영역
- 사용자가 특정 시대, 문화권, 언어를 선호하는지

### Round 2: 좁히고 추천하기

사용자가 말한 영역을 바탕으로 후보 2-3명을 추천한다. 다음 순으로 우선한다:
1. 시스템에 이미 Skill로 증류되어 있는 인물
2. 공개 자료가 풍부한 인물 (저서, 긴 인터뷰, 기록된 의사결정)
3. 사고가 충분히 독특해 높은 품질의 Skill을 만들 수 있는 인물

```text
말씀하신 내용을 바탕으로 한 후보입니다:

1. {Name A} — {한 줄 이유}
2. {Name B} — {한 줄 이유}
3. {Name C} — {한 줄 이유}

이 중에 맞는 사람이 있나요? 아니면 다른 사람을 말씀해 주세요.
```

사용자가 고르면 Q1로 진행한다.

---

## 오프닝 (직접 경로)

```text
공개 인물을 Skill로 증류해 드리겠습니다. 질문 5개에 답해 주세요. Q1을 제외한 모든 질문은 건너뛸 수 있습니다.
```

---

## 질문

### Q1: 누구인가

```text
누구를 증류할까요?

예:
- Steve Jobs
- Naval Ravikant
- 장이밍
- Charlie Munger
- Richard Feynman
```

수집 항목:
- 정식 이름
- 별칭
- 예상되는 언어 / 지역
- 이 인물이 널리 알려져 있는지 (자료 풍부) 또는 비교적 알려지지 않았는지

### Q2: 왜 이 인물인가

```text
이 인물의 Skill에서 무엇을 얻고 싶으신가요?

예:
- 어떻게 의사결정을 하는지
- 제품을 어떻게 사고하는지
- 복잡한 개념을 어떻게 설명하는지
- 사람과 트레이드오프를 어떻게 판단하는지
- 리스크와 불확실성을 어떻게 다루는지
```

수집 항목:
- 사용 사례
- 원하는 관점 / 초점 영역
- 산출물 성향: 전략 / 표현 / 설명 / 판단 / 창의성

### Q3: 알고 있는 자료

```text
이미 가지고 있는 원자료가 있나요? 책, 인터뷰, 강연, 게시물, 팟캐스트, 기사, 스크린샷 등 무엇이든 좋습니다.

로컬 파일(PDF, 전사본, 자막 파일, 스크린샷)이 있으면 지금 말씀해 주세요.
```

수집 항목:
- 로컬 자료 (사용자가 직접 제공할 수 있는 파일)
- 알고 있는 특정 출처의 URL
- 제목으로 아는 저서 / 강연 / 인터뷰
- 로컬 우선 모드로 진행해야 하는지

### Q4: 수집 전략

Q3을 바탕으로 수집 전략을 정하고 확인받는다:

```text
말씀하신 내용을 바탕으로 다음 수집 방식을 쓰겠습니다:

  [A] 로컬 우선: 로컬 자료가 상당히 있습니다. 그것부터 분석하고,
      빠진 항목만 웹에서 검색하겠습니다.

  [B] 웹 + 로컬: 자료가 일부 있습니다. 웹 조사와 결합하겠습니다.

  [C] 웹 전용: 로컬 자료가 없습니다. 웹 조사를 전면적으로 수행하겠습니다.

맞습니까? (확인 / 변경)
```

세 전략은 Phase 1 조사에서 노력을 어떻게 배분할지에 영향을 준다:
- **로컬 우선**: 제공된 자료를 먼저 분석하고, 6개 항목 중 어디가 채워졌는지 파악한 뒤, 빈 곳만 웹에서 검색한다
- **웹 + 로컬**: 6개 항목 웹 조사를 전면 수행한 뒤 로컬 자료와 병합하고, 겹치는 부분은 로컬을 기준값으로 삼는다
- **웹 전용**: 표준 6개 항목 웹 조사를 수행한다

### Q5: 조사 깊이

```text
어떤 조사 프로파일로 할까요?

- budget-friendly: 더 빠르고 가볍게, 최소 3트랙
- budget-unfriendly: 더 느리고 깊게, 6트랙 + audit·synthesis·validation 게이트

기본값: budget-friendly
```

수집 항목:
- 요청된 조사 프로파일
- 사용자가 속도를 선호하는지 확신도를 선호하는지

---

## 자료 부족 인물 감지

Q1 이후, 이 인물에게 충분한 공개 자료가 있는지 추정한다.

자료 부족 인물의 신호:
- Wikipedia 문서가 없거나 매우 짧다
- 출간된 저서나 장문 인터뷰가 없다
- 소셜 미디어 활동으로만 존재한다
- 사용자가 구체적인 저작이나 강연을 대지 못한다

자료 부족 인물로 감지되면:

```text
⚠️ 참고: {name} 은(는) 공개 자료가 제한적으로 보입니다.

이는 다음을 의미합니다:
- 멘탈 모델이 2-3개로 제한됩니다 (3-7개 대신)
- 일부 항목은 "제한된 정보 기반"으로 표기될 수 있습니다
- 정직한 한계 서술 섹션이 평소보다 커집니다

괜찮습니다. 정직한 60점짜리 Skill이 꾸며낸 90점짜리보다 낫습니다.

계속할까요? (예 / 다른 사람으로 변경)
```

```text
요약:

  인물: {name}
  지역/언어: {region}
  주요 목표: {goal}
  알려진 출처: {source_summary}
  수집 전략: {로컬 우선 / 웹+로컬 / 웹 전용}
  조사 프로파일: {research_profile}
  자료 부족 인물: {예/아니오}

확인할까요? (확인 / 수정 [필드])
```
