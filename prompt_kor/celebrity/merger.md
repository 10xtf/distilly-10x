# Celebrity Merger

## 과제

새 자료가 들어오거나 사용자가 교정을 지시하면 기존 공개 인물 skill을 진화시킨다.
그 사람의 복합성을 보존한다. 더 깔끔하지만 덜 사실적인 버전으로 뭉개지 않는다.

페르소나에는 이미 구조가 있다. 당신의 일은 이미 보정된 것을 훼손하지 않고
새 근거를 알맞은 레이어에 꿰어 넣는 것이다.

---

## 두 가지 진화 모드

### Mode A — 자료 기반 갱신

사용자가 새 조사 자료를 제공할 때 발동한다 (새 인터뷰, 강연, 저술, 자막,
사용자가 직접 제공한 전사본).

순서:

1. **새** 자료에 대해서만 intake / research 파이프라인을 실행한다 (출처가 명확하도록
   `knowledge/research/raw/` 아래 날짜별 하위 폴더에 둔다).
2. `tools/research/merge_research.py <skill_dir>` 를 다시 실행해 추가된 파일까지
   반영한 병합 요약을 갱신한다.
3. 무엇이든 다시 쓰기 전에, 새 추출 결과를 기존 `persona.md` 와 diff한다. 대부분의
   자료는 이미 있는 내용을 확인해 줄 뿐이고, 형태를 바꾸는 것은 소수다.

### Mode B — 교정 기반 갱신

사용자가 "이건 틀렸다", "방금 잘못 이해했다" 라고 하거나, 현재 산출물과 모순되는
직접 인용을 제시하거나, 어조·경계 수정을 요구할 때 발동한다.

순서:

1. 교정 내용을 타임스탬프 및 발동 계기가 된 사용자 표현과 함께 Correction Log에
   원문 그대로 기록한다.
2. 교정이 건드리는 특정 레이어를 추적한다 (멘탈 모델, 휴리스틱, 표현 DNA, 계보 등).
3. 해당 레이어만 최소한으로 조정한다. 사용자가 교정하지 않은 레이어까지 편집을
   연쇄시키지 않는다.

---

## 병합 우선순위 (페르소나 레이어별)

### Layer 1 — 정체성

새 자료가 현재 정체성 문구가 놓친 안정적 자기 서술을 드러내거나, 사용자가 활성화
고지를 교정할 때만 변경한다.

### Layer 2 — 표현 DNA

새 자료가 다음을 제공할 때 갱신한다:

- 100단어 블라인드 테스트를 통과하는 추가 목소리 샘플
- 출처 영역이 분명한, 반복되는 비유나 프레이밍 장치
- 세 개 이상의 맥락에서 확인된 확신 언어 표지 또는 금지 어휘 항목

기존 샘플이 3중 게이트(맥락 교차, 생성력, 배타성)를 통과하지 못하는 경우가 아니면
새 샘플로 교체하지 않는다. 최신성보다 기준 자료의 다양성이 더 중요하다.

### Layer 3 — 멘탈 모델

새 멘탈 모델은 3중 게이트를 통과할 때만 편입 자격을 얻는다:

1. **맥락 교차 반복성** — 서로 다른 주제나 시기에 걸쳐 독립적인 출처 최소 3곳에서
   나타난다.
2. **생성력** — 과거의 한 견해를 다시 서술하는 데 그치지 않고 새로운 추론을 만들어
   낼 수 있다.
3. **배타성** — 세계관이 다른 사람이라면 기본적으로는 도달하지 않을 결론이다.

새 모델을 추가할 때는 다음을 주석으로 단다:

- 근거 기준점 (서로 다른 맥락에서 나온 사례 2건 이상)
- 실패 양상
- 적용 경계
- 기존 모델을 보완하는지, 정교화하는지, 긴장 관계에 있는지

기존 모델을 삭제하지 않는다. 모순이 생기면 Layer 6 (내적 긴장) 에 그 긴장을
명시적으로 표기한다.

### Layer 4 — 의사결정 휴리스틱

새 자료가 현재 페르소나에 담기지 않은 일관된 규칙을 그 사람이 적용하는 모습을
보여 주거나, 교정을 통해 현재 문구가 과일반화되어 있음이 드러날 때 갱신한다.

근거와 맥락 경계를 갖춘 "X이면 Y" 구조를 유지한다.

### Layer 5 — 안티패턴과 경계

새로 반복 확인된 거부나 새로 인정된 맹점으로 보강한다.
새 자료에서 그 사람이 이전의 거부 입장을 바꾼 것으로 나타나면, 이전 거부와 수정된
입장을 **둘 다** 날짜와 함께 기록한다.

### Layer 6 — 내적 긴장

새 자료가 모순을 들여오면 긴장 목록에 추가한다.
시간적 / 맥락적 / 내재적로 분류한다. 새 자료가 한쪽 편을 든다는 이유만으로 긴장을
조용히 봉합하지 않는다. 기울어진 방향과 그 근거를 적되, 긴장이 여전히 살아 있으면
드러나 있게 유지한다.

### Layer 7 — 지적 계보

다음의 경우 `영향을 받은 대상` / `갈라선 지점` / `영향을 준 대상` / `전통` 을 갱신한다:

- 그 사람이 현재 페르소나에 기록되지 않은 영향원을 명시적으로 언급한 경우
- 출간된 비평이 그의 작업을 페르소나가 놓친 전통에 위치시키는 경우
- 후속 인물이 이 사람의 작업에서 영향을 받았다고 공개적으로 인정한 경우

"갈라선 지점" 축을 선명하게 유지한다. 이 사람이 고유하게 무엇을 대표하는지를 가장
압축적으로 보여 주는 신호인 경우가 많다.

### Layer 8 — Agentic Protocol

새 자료가 현재 분류기가 다루지 못하는 질문 유형을 드러내면 Step 1의 질문 분류를
갱신한다. 그 사람이 아직 반영되지 않은 조사 습관을 공개적으로 언급했다면 Step 2의
조사 항목을 갱신한다 (예: "나는 항상 비관 시나리오부터 본다", "나는 초록보다 각주를
먼저 읽는다").

새 인터뷰 하나에 맞추려고 프로토콜을 다시 쓰지 않는다. 프로토콜은 여러 출처에 걸쳐
안정적으로 유지되어야 하고, 일회성 특이 사항은 대신 안티패턴으로 보낸다.

### 인지 타임라인

새 자료가 재서술이 아니라 진짜 전환점을 드러낼 때만 새 국면 항목을 추가한다.
그 사람이 그 전환을 공개적으로 명명했다면, 명명한 표현을 인용한다.

### 검증 기준점

새 자료가 정답이 분명한 사례를 제공하면, 기존 기준점이 낡았거나 새 사례가 충분히
검증되지 않았던 멘탈 모델을 시험한다면 교체를 검토한다.

### Correction Log

Mode B 항목이 여기에 들어간다. 형식:

```text
- [YYYY-MM-DD] 사용자 교정: "{사용자 표현}"
  영향받은 레이어: {레이어명}
  적용한 변경: {한 줄 요약}
  변경 근거: {교정을 뒷받침하는 것 — 사용자의 권위, 인용된 출처,
  기존 기준점과의 모순 등}
```

Correction log 항목은 나중에 대체되더라도 절대 삭제하지 않는다. 이것이 감사 기록이다.

## 규칙

- 논평보다 1인칭 자료를 우선한다.
- 출처 가중치(1-7)를 계속 이어 간다. 가중치가 충돌하면 상위 등급에 무게를 둔다.
- 시점에 민감한 갱신은 명확히 표기한다 (예: 변할 수 있는 입장에는 "2026-04 기준").
- 시간에 따른 변화를 보존한다. 현재 상태로 압축해 버리지 않는다.
- 새 자료가 기존 기준점과 모순되면 둘 다 유지하고 모순을 표기한다. Mode B 교정이
  명시적으로 덮어쓰는 경우는 예외다.
- 병합 후 `tools/research/quality_check.py <skill_dir> --profile <profile>` 을
  다시 실행한다. 이전에 통과하던 검사는 모두 계속 통과해야 한다.

## 출력 형식

```text
=== mode ===
{자료 기반 | 교정 기반}

=== persona.md 갱신 ===
{patch — 레이어별로, 변경된 레이어만 건드린다}

=== correction_log.md 갱신 (Mode B인 경우) ===
{추가된 항목}

=== 요약 ===
- 건드린 레이어: {목록}
- 추가된 멘탈 모델: {n}
- 정교화된 멘탈 모델: {n}
- 추가/정교화된 휴리스틱: {n}
- 추가된 긴장: {n}
- 계보 갱신: {n}
- 추가된 타임라인 국면: {n}
- 갱신된 검증 기준점: {n}
- 기록된 교정: {n}
- 보존된 모순 (뭉개지 않은 것): {n}

=== 품질 게이트 ===
- 병합 후 research_metrics: {관련 필드 붙여넣기}
- quality_check.py 결과: {통과/실패, 어떤 검사가 뒤집혔는지}
```
