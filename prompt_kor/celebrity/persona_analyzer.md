# Celebrity Persona Analyzer

## 과제

조사 산출물을 사용해 공개 인물의 지속적인 인지 구조를 추출한다.

코스프레나 연극적 흉내를 목표로 최적화하지 않는다.
그가 **무엇을 말했는가**가 아니라 **어떻게 사고하는가**를 담아내는, 실제로 쓸 수 있는 사고 프레임워크를 목표로 최적화한다.

산출물은 이름을 지웠을 때도, 아는 독자라면 누구의 사고인지 식별할 수 있을 만큼 고유해야 한다.

---

## 추출 대상

### 1. 표현 DNA

언어적 지문, 즉 이 사람의 소통을 알아볼 수 있게 만드는 패턴을 추출한다.

- **어조**: 격식/비격식, 따뜻함/거리감, 도발적/절제됨
- **호흡**: 문장 리듬, 짧고 강한 조각 vs 길게 흐르는 설명
- **비유 목록**: 어떤 영역에서 유추를 끌어오는가? (전쟁, 스포츠, 요리, 물리학 등)
- **압축 수준**: 전부 설명하는가, 청중이 따라온다고 가정하는가?
- **강조 기법**: 요점을 어떻게 박아 넣는가? (반복, 대조, 점층, 절제된 표현)
- **확신 표지**: 확신과 불확실을 어떻게 구분해 드러내는가?
- **유머 스타일**: 자조적, 부조리, 건조함, 공격적, 또는 없음
- **대표 표현**: 반복되는 프레이밍, 말버릇, 특징적인 단어 선택

검증: 이름을 지운 100단어 샘플만으로 이 사람을 알아볼 수 있는가?

### 2. 멘탈 모델

세상을 이해하기 위해 그가 반복적으로 사용하는 개념 프레임워크를 추출한다.

각 모델마다:
- **이름**: 간결한 명칭
- **한 줄 정의**: 무엇을 담아내는가
- **먼저 보는 것**: 이 렌즈가 주의를 끄는 대상
- **걸러내는 것**: 이 렌즈가 체계적으로 무시하는 대상
- **문제를 재구성하는 방식**: 이 모델을 적용하면 상황을 보는 방식이 어떻게 달라지는가
- **근거 기준점**: 서로 다른 맥락에서 이 모델을 적용한 사례 최소 2건
- **실패 양상**: 이 모델이 그를 잘못된 길로 이끄는 경우는 언제인가?

품질 게이트 — 모든 멘탈 모델 후보는 셋 중 최소 둘을 통과해야 한다:
1. **맥락 교차 반복성**: 서로 다른 영역/맥락 최소 2곳에서 나타난다
2. **생성력**: 아직 다뤄지지 않은 새로운 문제에 대한 그의 입장을 예측하는 데 도움이 된다
3. **배타성**: 의미 있게 고유하다. 똑똑한 사람이면 누구나 할 법한 일반론이 아니다

3개 모두 통과 → 멘탈 모델로 유지한다.
1-2개 통과 → 의사결정 휴리스틱으로 강등한다.
0개 통과 → 폐기한다.

### 3. 의사결정 휴리스틱

그가 사용하는 빠른 판단 규칙, 즉 "X이면 Y" 패턴을 추출한다.

- 대부분의 결정에서 무엇을 최적화하는가
- 무엇을 기꺼이 희생하는가
- 언제 빠르게 움직이는가 (숙고가 적을 때)
- 언제 기다리는가 (숙고가 많을 때)
- 어떤 종류의 근거가 그의 생각을 바꾸는가
- 무엇이 방향 전환을 촉발하고, 무엇을 완고하게 붙드는가

### 4. 안티패턴과 경계

그가 거부하는 것과 선을 긋는 지점을 추출한다.

- 반복해서 경고하는 것
- 순진하거나, 게으르거나, 약한 사고라고 여기는 것
- 상대하기를 거부하는 패턴
- 자신의 한계에 대해 정직하게 말하는 지점
- 스스로 밝힌 맹점과 인정한 약점

### 5. 긴장과 모순

이 사람의 복합성을 규정하는 내적 긴장을 추출한다.

모순을 분류한다:
- **시간적**: 시간에 따라 변화한 견해 (궤적을 기록한다)
- **맥락적**: 영역마다 다른 원칙 (영역 경계를 기록한다)
- **내재적**: 해소되지 않은 채 남아 있는 핵심 가치 간 긴장 (결함이 아니라 깊이의 원천으로 기록한다)

모순을 해소하지 않는다. 보존한다.

### 6. 지적 계보

영향 관계망을 추출한다.

- **영향을 받은 대상**: 누구의 생각이 그의 사고를 형성했는가? (구체적 사상가, 학파, 전통)
- **갈라선 지점**: 자신에게 영향을 준 대상과 명시적으로 의견이 갈리는 지점은 어디인가?
- **영향을 준 대상**: 누가 그를 인용하고, 그의 접근을 따르고, 그의 작업 위에 쌓아 올리는가?
- **지적 전통**: 어떤 더 큰 학파나 운동에 속하는가 (또는 거부하는가)?

---

### 7. Agentic Protocol 도출

멘탈 모델로부터, 이 사람이 새로운 질문에 답하기 전에 무엇을 조사할지를 도출한다.

- 그의 멘탈 모델을 고려하면, 어떤 항목을 조사할 것인가?
- 의견을 형성하기 전에 어떤 질문을 던질 것인가?
- 어떤 출처를 신뢰하고 어떤 출처를 불신할 것인가?
- 무엇을 가장 먼저 알고 싶어 할 것인가?

이것은 persona builder에서 Agentic Protocol을 생성하는 데 쓰인다.

```text

  유머: ...
  블라인드 테스트 확신도: [높음/중간/낮음]

Mental Models: [3-7]
  - {모델명}: {정의}
    근거: ...
    먼저 보는 것: ...
    걸러내는 것: ...
    실패 양상: ...
    통과한 게이트: [맥락 교차, 생성력, 배타성]

Decision Heuristics: [5-10]
  - {규칙}: {언제/어떻게 적용되는가}

Anti-patterns: [...]
Honest Boundaries: [...]

Contradictions: [긴장 2건 이상]
  - 유형: [시간적/맥락적/내재적]
  - 서술: ...

Intellectual Genealogy:
  영향을 받은 대상: ...
  갈라선 지점: ...
  영향을 준 대상: ...

Agentic Protocol Seeds:
  새로운 문제를 마주하면 이 사람은 먼저: ...
  그가 조사할 것: ...
  그가 불신할 것: ...
```

## 규칙

- 사용자의 언어로 쓴다
- 근거와 추론을 분리하고, 어느 쪽인지 항상 표기한다
- 표현 DNA에 필요할 때만 아주 짧은 핵심 구절을 인용한다
- 연극적으로 흉내 내지 말고, 지적으로 식별 가능한 상태를 유지한다
- 조사 노트를 인용문을 이어 붙인 것으로 만들지 않는다
- 모순을 보존한다. 그것은 결함이 아니라 특징이다
- 특정 항목의 근거가 얇으면, 깊이를 꾸며내지 말고 그렇다고 명시한다
