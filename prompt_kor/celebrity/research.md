# Celebrity Research Prompt (Budget-Friendly)

## 과제

증류 전에 공개 인물에 대한 구조화된 다차원 조사를 수행한다.

목표는 잡다한 사실을 모으거나 전기를 편찬하는 것이 아니다.
목표는 다음을 재구성하기에 충분한, 근거가 있는 증거를 확보하는 것이다:

- 멘탈 모델 (어떻게 사고하는가)
- 의사결정 휴리스틱 (어떻게 선택하는가)
- 표현 DNA (어떻게 말하는가)
- 안티패턴 (무엇을 거부하는가)
- 정직한 한계 (증거가 어디서 끊기는가)

---

## 선별 원칙

무엇을 수집하고 무엇을 건너뛸지는 다음 원칙을 따른다:

1. **장문 > 단편**: 3,000단어 에세이 하나가 트윗 50개보다 사고 구조를 더 많이 드러낸다
2. **논쟁 > 합의**: 논란이 된 입장이 모두가 칭찬하는 입장보다 그 사람 고유의 사고를 더 잘 드러낸다
3. **변화 > 고정**: 생각을 바꾼 지점이 일관되게 유지한 지점보다 정보량이 많다
4. **1차 > 2차**: 본인의 말이 언제나 남의 요약보다 우선한다
5. **작업 방식에 대한 논의 > 전기**: 자기 프로세스를 어떻게 이야기하는지가 생애사보다 중요하다
6. **반복 패턴 > 일회성 인용**: 여러 맥락에서 5번 나타나는 패턴이 바이럴된 문장 하나보다 낫다

## 출처 품질 위계

다음 순서로 출처를 우선한다:

1. **사용자가 제공한 로컬 자료** (전사본, PDF, 스크린샷 — 기준값)
2. **1인칭 저작물** (책, 에세이, 뉴스레터, 블로그 글)
3. **장문 인터뷰와 대담** (팟캐스트, 30분 이상 인터뷰, 파이어사이드 챗)
4. **기록된 의사결정과 전환점** (사례 연구, 공개 기록, 보도된 행동)
5. **단문 1인칭 콘텐츠** (소셜 미디어 게시물, 짧은 Q&A, 트윗/스레드)
6. **외부 분석과 비평** (프로필 기사, 서평, 타인이 쓴 전기)
7. **2차 요약** (다른 것이 전혀 없을 때만 사용)

### 출처 블랙리스트

다음 출처는 영구 제외한다. 절대 근거로 인용하지 않는다:

**중국어권:**
- Zhihu — 검증 불가능한 익명 답변, 전언이 많음
- WeChat 공식 계정 — 대부분 2차 콘텐츠를 재포장한 것
- Baidu Baike — 신뢰할 수 없고, 오래되었거나 홍보성인 경우가 많음

**공통:**
- 콘텐츠 팜과 SEO 최적화된 요약 사이트
- AI가 생성한 인물 소개 페이지
- 리스티클 ("X에게서 배우는 10가지 교훈") — 1차 출처를 링크와 함께 인용한 경우 제외
- 1차 출처로서의 Wikipedia (실제 출처를 찾기 위한 길잡이로만 허용)

### 지역별 권장 출처

**중국어권 인물:**
- Bilibili 오리지널 영상, 특히 장문 인터뷰
- Xiaoyuzhou 팟캐스트
- 권위 있는 매체: 36Kr, LatePost, Caixin, GeekPark, Huxiu
- 공식 Weibo (인증 계정, 직접 작성한 게시물만)
- 출간된 저서 (정식 경로를 통해)

**영어권 인물:**
- YouTube 장문 인터뷰 (Lex Fridman, Tim Ferriss 등)
- 개인 블로그와 뉴스레터
- 출간된 저서와 에세이
- 팟캐스트 전체 회차 (클립이 아님)
- 권위 있는 프로필 기사: New Yorker, Atlantic, Bloomberg, Wired

### 자막 없는 콘텐츠 다루기

자막 없는 장문 인터뷰와 팟캐스트는 표현 DNA와 즉석 추론의 가장 풍부한 출처인 경우가 많다.
건너뛰지 않는다. 다만 이 Skill은 외부 서비스를 호출하지 않으므로, 사용자가 전사본이나
발췌를 직접 제공해야 한다.

전사본을 받으면 한 번 읽고, 타임스탬프와 함께 의역한 발견 사항을 추출한 뒤 버린다.
**전체 전사본을 skill 디렉터리에 커밋하지 않는다.** `knowledge/research/raw/` 에는
출처 메타데이터가 붙은 짧은 의역 노트만 들어간다.

### 단문 1인칭 게시물

단문 1인칭 게시물이 조사 공백을 메워 줄 때는 사용자가 해당 게시물의 퍼머링크나 발췌를
직접 제공해야 한다. 자동 수집 도구는 제공하지 않는다. 작성자를 검증하고 각 게시물의
개별 퍼머링크를 열어 본 뒤 선택한다. 그런 다음 관련 근거만 안전하게 의역해 해당 raw
노트에 URL과 출처 가중치를 붙여 기록한다. 검색 페이지와 프로필 루트는 절대 근거 있는
출처로 세지 않는다.

## 6개 항목 병렬 수집 전략

조사는 6개 항목을 다뤄야 한다. 각 항목을 독립된 조사 트랙으로 생각한다.
하나의 거대한 노트를 쓰지 않는다. 각 항목은 자체 조사 파일을 만든다.
전체 조사를 하나의 거대한 노트로 뭉치지 않는다.

### 항목 1: 저술

**대상**: 본인이 직접 쓴, 체계적이고 숙고된 입장.

검색 대상:
- 저서, 챕터, 핵심 구절 (전문이 아니라 제목과 논지 단위로)
- 에세이, 블로그 글, 뉴스레터
- 공개된 편지, 메모, 내부 문서
- 여러 저술에 걸쳐 반복되는 핵심 주장

**추출할 것**: 핵심 명제, 추론 사슬, 논증을 쌓아 가는 방식.

### 항목 2: 대담

**대상**: 즉석에서, 압박 속에서, 대화 중에 어떻게 사고하는가.

검색 대상:
- 장문 팟캐스트 출연 (30분 이상)
- 실질적인 Q&A가 있는 영상 인터뷰
- 패널 토론과 논쟁
- AMA / Q&A 세션

**추출할 것**: 예상치 못한 질문을 다루는 방식, 이견을 표현하는 방식, 반복해서 되돌아가는 지점.

### 항목 3: 표현 DNA

**대상**: 언어적 지문. 무엇을 말하는가가 아니라 어떻게 말하는가.

여러 출처에 걸쳐 분석한다:
- 문장의 리듬과 평균 길이
- 비유 빈도와 선호하는 유추
- 이견을 구성하는 방식 (직설적인가? 외교적인가? 냉소적인가?)
- 압축 수준 (전부 설명하는가, 청중이 따라온다고 가정하는가?)
- 반복되는 표현, 말버릇, 고유한 프레이밍
- 유머 스타일 (있다면): 자조적, 부조리, 건조함, 공격적

**추출할 것**: "100단어 블라인드 테스트"를 통과할 스타일 표지. 이름을 지운 한 단락만 보고
이 사람을 알아볼 수 있는가?

### 항목 4: 의사결정

**대상**: 말한 것이 아니라 실제로 한 것.

검색 대상:
- 큰 베팅과 그 이유
- 방향 전환 — 어디서 방향을 바꿨고 무엇이 계기였는지
- 명시적으로 선택한 트레이드오프 (무엇을 위해 무엇을 희생했는지)
- 공개적으로 언급한 실패
- 무엇을 최적화했고 무엇을 의도적으로 무시했는지

**추출할 것**: 의사결정 패턴, 리스크 감수 성향, 어떤 종류의 근거가 그를 움직이는지.

### 항목 5: 외부 시각

**대상**: 남들이 그를 어떻게 보는가. 특히 자기 인식과 외부 인식의 간극.

검색 대상:
- 비판과 부정적 평가 (칭찬만이 아니라)
- 남들이 지적한 모순
- 협업자, 반대자, 후임자가 그를 묘사하는 방식
- 남들이 짚어낸 알려진 맹점

**추출할 것**: 다른 사람들의 머릿속에 존재하는 이 인물의 버전. 특히 본인의 자기 서사와 갈리는 지점.

### 항목 6: 타임라인

**대상**: 언제 무슨 일이 있었는가가 아니라, 사고가 어떻게 변해 왔는가.

구성 대상:
- 인지적 영향을 남긴 주요 이정표 (단순 전기적 사건이 아니라)
- 지적 전환점 — 핵심 신념이 언제 바뀌었는가?
- 최근 동향 (최근 12-24개월) 중 현재 사고에 영향을 줄 수 있는 것
- 국면 전환: 그의 공개적 사고에 뚜렷이 구분되는 시기가 있었는가?

**추출할 것**: 이력서가 아니라 사고의 궤적.

## 자료 부족 인물 프로토콜

조사 중 특정 항목의 자료가 매우 얇다는 것을 발견하면:

1. 공백을 메우기 위해 근거, 인용문, 귀속을 **지어내지 않는다**
2. 무엇이 없는지 메모와 함께 해당 항목을 **얇다고 명시적으로 표기한다**
3. **기대치를 낮춘다**: 근거 있는 출처 총합이 10건 미만이면 자료 부족 인물이다
4. 자료 부족 인물의 경우:
   - 멘탈 모델을 최대 2-3개로 제한한다
   - 근거가 얇은 모델은 "제한된 정보 기반" 으로 표기한다
   - 정직한 한계 섹션을 확장한다
   - 어떤 자료를 추가하면 Skill이 좋아지는지 사용자에게 알린다

## 필수 산출물 계약

`knowledge/research/raw/` 아래에 raw 노트 파일을 최소 3개 만든다:

- `01_core_profile.md` — 항목 1 + 6 (저술 + 타임라인)
- `02_conversations_and_material.md` — 항목 2 + 4 (대담 + 의사결정)
- `03_expression_and_reception.md` — 항목 3 + 5 (표현 DNA + 외부 시각)

각 파일은 다음 구조를 따라야 한다:

```md
# <트랙 제목>

## Dimension Coverage
- 다룬 항목: [목록]
- 사용한 수집 전략: [웹 전용 / 웹+로컬 / 로컬 우선]

## Source Metadata
- URL: ...
- 출처 유형: 인터뷰 / 책 / 에세이 / 강연 / 팟캐스트 / 소셜 게시물 / 기사 / 프로필
- 근거 수준: 1차 / 2차
- 접근 메모: 공개 / 부분 / 차단됨
- 출처 가중치: [1-7, 위 위계 기준]

## Key Findings
- ...

## Patterns and Repeated Themes
- ...

## Contradictions
- ...

## Inferences (사실이 아니라 추론임을 명확히 표기)
- ...

## Gaps and Missing Information
- ...
```

### 최소 품질 기준

노트 전체를 통틀어:

- raw 노트 파일 최소 3개
- 근거 있는 출처 URL 최소 2개 (실제로 열어 본 페이지. 홈페이지 아님)
- 모든 파일에서 근거와 추론이 명확히 분리되어 있을 것
- 모순 최소 1건 식별 (또는 발견되지 않았다는 명시적 메모)
- 공백 최소 1건 인정

### URL 근거 규칙

다음은 근거 있는 출처로 **세지 않는다**:

- 플랫폼 홈페이지 (youtube.com, weibo.com, bilibili.com)
- 검색 결과 페이지 (/search, /s?)
- 주제 또는 태그 페이지 (/topic/, /tag/)
- 개별 콘텐츠가 없는 프로필 루트
- 자리 표시용 경로 (v.qq.com/detail/)
- 실제로 열어서 읽지 않은 모든 URL

## 품질 체크포인트

조사를 마친 뒤 분석으로 넘어가기 전에, 구조화된 품질 요약을 산출한다:

```
┌──────────────────────────────┬──────────┬─────────────────────────────┐
│ 항목                          │ 출처 수   │ 핵심 발견                    │
├──────────────────────────────┼──────────┼─────────────────────────────┤
│ 1 저술                        │ N        │ [핵심 명제 / 공백]           │
│ 2 대담                        │ N        │ [핵심 패턴 / 공백]           │
│ 3 표현 DNA                    │ N        │ [스타일 표지 / 공백]         │
│ 4 의사결정                     │ N        │ [의사결정 패턴 / 공백]       │
│ 5 외부 시각                    │ N        │ [외부 관점 / 공백]           │
│ 6 타임라인                     │ N        │ [궤적 / 공백]               │
├──────────────────────────────┼──────────┼─────────────────────────────┤
│ 발견된 모순                    │ N        │ [요약]                      │
│ 얇은 항목                      │ [목록]   │ 보완: [계획]                 │
│ 자료 부족 인물?                 │ 예/아니오 │                             │
└──────────────────────────────┴──────────┴─────────────────────────────┘
```

이것을 사용자에게 제시하고 확인을 받은 뒤 분석으로 넘어간다.
사용자가 문제를 지적하거나 특정 항목의 깊이를 더 원하면 조사를 연장한다.

## 출력 규칙

- 다음을 명확히 구분한다:
  - 그가 말한 것 (1차, 인용 또는 의역)
  - 그가 한 것 (기록된 행동)
  - 남들이 그에 대해 말한 것 (외부, 귀속 표시)
  - 당신이 추론한 것 (추론으로 표기)
- 모순을 남겨 둔다. 그것은 결함이 아니라 특징이다
- 넓이보다 깊이를 우선한다
- 사용자의 언어로 쓴다
- 출처, URL, 인용문, 서지 정보를 절대 지어내지 않는다
- 일반 홈페이지나 플랫폼 루트를 가짜 근거로 쓰지 않는다
- 실제로 열어서 확인한 URL만 기록한다
- 검증된 외부 출처를 확보할 수 없으면 그렇다고 명시한다
- 전체 전사본이나 대량의 자막 덤프를 skill 디렉터리에 저장하지 않는다
- 직접 인용은 짧고 드물게 유지한다
- 복사한 구절보다 출처 메타데이터가 붙은 의역 노트를 우선한다

## 저작권 안전

- 전체 전사본 저장 금지
- 책, 자막, 인터뷰의 긴 구절 인용 금지
- 의역 노트 + 출처 메타데이터만
- 표현 DNA를 담는 데 반드시 필요한 경우에만 짧은 인용 조각 허용
