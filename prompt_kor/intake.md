# 기본 정보 입력 스크립트

## 오프닝

```
이 동료의 Skill을 만들어 드리겠습니다. 질문 3개만 답하시면 되고, 각 질문은 건너뛸 수 있습니다.
```

---

## 질문 순서

### Q1: 별칭/코드명

```
이 동료를 어떻게 부르나요? (별칭, 닉네임, 코드명 모두 가능. 여러 단어는 - 로 연결)

예: gil-dong
```

- 임의의 문자열을 받는다
- 생성되는 slug는 `-` 로 통일해 연결한다 (밑줄은 쓰지 않는다)
- 한글 이름은 로마자 별칭을 직접 받는다 ("홍길동" → `gil-dong`).
  한글을 그대로 넣으면 slug 생성기가 `person-<해시>` 로 떨어져 알아볼 수 없다
- 영어는 소문자로 바꿔 `-` 로 연결한다 ("Big Mike" → `big-mike`)

---

### Q2: 기본 정보

회사, 직급, 직위, 성별을 한 질문에 넣어 사용자가 한 문장으로 답하게 한다:

```
그의 기본 정보를 한 문장으로 설명해 주세요. 회사, 직급, 직위, 성별 중 떠오르는 대로 쓰시면 되고 건너뛰어도 됩니다.

예: 바이트댄스 2-1 백엔드 엔지니어 남
```

사용자의 답변에서 다음 필드를 파싱한다 (없으면 비워 둔다):
- **회사**
- **직급**
- **직위**
- **성별**

#### 직급 대조 참고표

| 회사 | 직급 형식 | 엔지니어/연구원 | 시니어 엔지니어 | 책임/전문가 | Staff/Principal |
|------|---------|------------|---------|---------|----------------|
| 바이트댄스 | X-Y | 2-1, 2-2 | 3-1, 3-2 | 3-3 | 3-3+ (O급) |
| 알리바바 | P급 | P5, P6 | P7 | P8 | P9+ |
| 텐센트 | T급 | T1-1~T2-2 | T3-1, T3-2 | T4 | T4+ |
| 바이두 | T급 | T5, T6 | T7 | T8 | T9+ |
| 메이퇀 | P급 | P4, P5 | P6 | P7 | P8+ |
| 화웨이 | 숫자급 | 13-15 | 16-17 | 18-19 | 20-21 |
| 넷이즈 | P급 | P1-P3 | P4 | P5 | P6+ |
| 징둥 | T급 | T3-T4 | T5 | T6 | T7+ |
| 샤오미 | 숫자급 | 1-3 | 4-5 | 6-7 | 8+ |

**회사 간 대략적 대응**:

```
바이트댄스 2-1/2-2  ≈  알리바바 P6   ≈  텐센트 T2  ≈  바이두 T6
바이트댄스 3-1      ≈  알리바바 P7   ≈  텐센트 T3-1 ≈  바이두 T7
바이트댄스 3-2      ≈  알리바바 P7+  ≈  텐센트 T3-2
바이트댄스 3-3      ≈  알리바바 P8   ≈  텐센트 T4
```

> 참고: 바이트댄스 2-1은 엔지니어 직급이고, 3-1부터 시니어 엔지니어다.
> 2-1은 알리바바 P6에 대략 해당하며, 업무를 독립적으로 수행하는 주력 엔지니어 급이다.

### Q3: 성격 프로필

MBTI, 별자리, 개성 태그, 기업문화 태그, 주관적 인상을 모두 합쳐 사용자가 자유롭게 서술하게 한다:

```
그의 성격을 한 문장으로 설명해 주세요. MBTI, 별자리, 개성, 몸에 밴 기업문화, 본인이 받은 인상 중
떠오르는 대로 쓰시면 되고 건너뛰어도 됩니다.

예: INTJ 염소자리 책임 회피 선수 바이트댄스식 CR은 아주 엄격한데 이유는 절대 설명 안 함
```

사용자의 답변에서 다음 필드를 식별해 추출한다 (없으면 비워 둔다):
- **MBTI**: 16가지 표준 유형
- **별자리**: 12별자리
- **개성 태그**: 아래 태그 목록에서 매칭하고, 직접 서술한 표현도 받는다
- **기업문화 태그**: 아래 태그 목록에서 매칭한다
- **주관적 인상**: 분류할 수 없는 자유 서술은 원문 그대로 보존한다

#### 개성 태그 목록

**업무 태도**: 성실 책임감 / 대충 넘어감 / 책임 회피 선수 / 총대 메는 사람 / 완벽주의 / 미루기

**소통 스타일**: 직설적 / 빙빙 돌림 / 말수 적음 / 말수 많음 / 음성 메시지 애용 / 읽고 답 안 함 / 읽고 엉뚱하게 답함 / 즉답 강박

**의사결정 스타일**: 결단력 있음 / 말 바꾸기 반복 / 상급자 의존 / 강하게 밀어붙임 / 데이터 기반 / 전적으로 감

**감정 스타일**: 감정 안정 / 유리 멘탈 / 쉽게 흥분 / 냉담하고 거리 둠 / 겉으로만 원만 / 비꼬는 말투

**화법과 수단**: PUA 선수 / 사내 정치 플레이어 / 책임 전가의 달인 / 상향 관리 전문가 / 훈계 좋아함 / 감정적 압박

#### 기업문화 태그 목록

- **바이트댄스식** — 솔직하고 직설적, impact 추구, 말 꺼내면 반드시 context부터, "정렬(对齐)"이라는 말을 즐겨 씀
- **알리바바식** — 6대 가치관(六脉神剑), "임파워먼트", "지렛대", "생태계", "선순환 구조" 같은 말을 즐겨 씀
- **텐센트식** — 데이터로 말함, 경마식 내부 경쟁, 절제되고 보수적, 사용자 경험 중시
- **화웨이식** — 분투자 문화, 프로세스 규범, PPT 보고 선호, 실행력 강조
- **바이두식** — 기술 지상주의, 위계 의식 강함, 내부 경쟁 치열
- **메이퇀식** — 극한의 실행, 디테일에 집착, 현지화 사고
- **제1원리** — 머스크식. 본질을 파고들고, 유추를 거부하며, 과감하게 단순화
- **OKR 신봉자** — 무슨 일이든 Objective부터 묻고, KR을 두고 깐깐하게 따짐
- **대기업 조립라인** — 규범은 잘 갖춰져 있으나 창의성은 낮음, SOP 의존, 책임지기를 두려워함
- **스타트업파** — 자원 부족, 풀스택 사고, 결과 지향, 혼란을 감내함
