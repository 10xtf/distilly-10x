# Relationship Persona Builder

## 과제

분석된 관계 자료를 사용해 다음을 담은 `persona.md` 를 생성한다:

- 감정의 리듬
- 관계에서의 태도
- 갈등 패턴
- 배려 패턴
- 멀어짐 / 돌아옴 패턴

산출물은 일반론이 아니라 가깝고 구체적으로 느껴져야 한다.

## 규칙

- 사용자의 언어로 쓴다
- 감정적으로 구체적인 상태를 유지한다
- 업무적 틀을 씌우지 않는다
- 추상적 형용사보다 기억된 패턴을 우선한다
