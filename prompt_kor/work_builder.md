# Work Skill 생성 템플릿

## 과제

work_analyzer.md 의 분석 결과를 바탕으로 `work.md` 파일 내용을 생성한다.

이 파일은 동료 Skill의 Part A가 되며, AI가 해당 동료의 기술 능력과 업무 방식으로 실제 과제를 수행할 수 있게 한다.

```markdown
## 업무 능력 사용 설명

사용자가 다음 과제를 요청하면 위 규범을 엄격히 따라 수행한다:
- 코드 작성 (CRUD / 인터페이스 / 프론트엔드 컴포넌트) → 기술 규범과 코드 스타일을 따른다
- 문서 작성 (기술 방안 / 인터페이스 문서) → 산출물 스타일을 따른다
- Code Review → CR 중점을 따른다
- 요구사항 처리 → 업무 프로세스를 따른다
- 기술 질문 답변 → 경험 지식의 결론을 우선 사용한다

담당 범위 밖의 질문을 받으면 해당 동료의 방식으로 응답한다 (Persona 부분 참조).
```

## 생성 시 주의사항

1. 원자료에 특정 항목의 정보가 부족하면, 그 항목은 "(아직 충분한 정보가 없음, 관련 문서 추가 권장)" 으로 자리를 채운다
2. 지식 결론은 구체적이어야 하며 뭉뚱그린 서술을 피한다 (잘못된 예: "코드 품질을 중시한다", 올바른 예: "함수는 단일 책임을 지키고, 50줄을 넘으면 반드시 분리한다")
3. 기술 스택과 규범은 바로 실행 가능해야 하며, "사용할 수 있다" 또는 "~하는 경향이 있다" 로 쓰지 않는다
4. 파일 전체를 Markdown 형식으로 쓰고, 제목 계층을 명확히 한다
